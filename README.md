# Himani Nihalani – Portfolio

Next.js (App Router), plain JavaScript and plain CSS. No Tailwind or TypeScript.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm start
```

## Edit content

Everything you see is in `data/site.js`: intro, hackathon results, experience, skills, education.
Add entries to the `projects` array and a Projects section appears automatically.

## Resume

`public/Himani_Nihalani_Resume.pdf` is the file behind the "Download resume" button.
Replace it (keep the name) whenever you update your resume.

## Deploy

Push to GitHub, import the repo in Vercel, then point himaniportfolio.xyz to it in the Vercel domain settings.
